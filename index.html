01 · 2025–2026 Graduation project

ComicMind

Full-stack AI platform for generating multi-panel comic stories from text prompts. React/TypeScript frontend, Node.js API, MongoDB persistence, JWT authentication, protected story management, OpenAI image generation, and Cloudinary image storage. Panel rendering runs on a durable generation pipeline built on MongoDB, so a worker resumes where it left off instead of losing a comic when a tab closes or a process restarts. Each job’s panels are embedded in its ledger document, so every claim, counter update and state transition is a single atomic write — which is what gives exactly-once rendering and idempotent submits without a separate broker.

Role
Full-stack developer
Scope
Idea → script → character-consistent panels in five art styles; drafts, public gallery, ratings and comments, PDF export
Reliability
Resumable queued rendering, verified by integration tests that kill the worker mid-generation against a real database
Proof
Final report, interim demos, VIVA

Why it matters: this is the clearest proof that I can connect product design, backend architecture, third-party APIs, media storage, and a polished frontend into one working application — then harden it, moving slow image work off the request path so a failure mid-generation is recoverable rather than fatal — and then simplify it, cutting the pipeline from three datastores to one without giving up any of those guarantees.
